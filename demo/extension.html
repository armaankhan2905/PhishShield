Get the PhishShield extension

Warns you inside Gmail and outlines risky links on any website, using this PhishShield server. Works in Google Chrome and Microsoft Edge.

Checking whether the extension is installed…

Install in four steps

  1. Download and unzip

    Get phishshield-extension.zip, then unzip it (Windows: right-click → Extract All). You'll get a folder called phishshield-extension.

    Download extension

  2. Open the extensions page

    Websites can't open this page for you. Copy the address, paste it into a new tab and press Enter.

    chrome://extensions

  3. Turn on Developer mode

    The switch is in the top-right corner of the extensions page.

  4. Click “Load unpacked”

    Choose the phishshield-extension folder from step 1. Then come back to this tab: it updates by itself once the extension is on.

Why isn't this one click?

For your safety, Chrome and Edge only allow one-click installs from their extension stores. Websites can't install extensions on their own. When PhishShield is published to the Chrome Web Store, the button above becomes Add to Chrome and installs it in one click.

The extension sends messages only to the PhishShield server you choose in its settings (by default this computer).
